# AI & Machine Learning Projects

A collection of end-to-end Machine Learning, Deep Learning, and Data Science projects covering classification, entity recognition, and privacy modeling.

---

## 🛠️ Included Projects

### 1. Breast Cancer Classification with Neural Networks
- **File:** `DL_Project_1_Breast_Cancer_Classification_with_NN.ipynb`
- **Overview:** A Deep Learning binary classification model built to detect breast cancer using clinical features. Includes data preprocessing, feature scaling, model training, evaluation metrics, and loss visualization.

### 2. Personally Identifiable Information (PII) Entity Recognition
- **File:** `Personally_Identifiable_Information_(PII)_Entity_Recognition (1).ipynb`
- **Overview:** An NLP model focused on identifying sensitive PII (names, emails, addresses, etc.) within unstructured text to help automate data privacy compliance and anonymization.

### 3. User Privacy Preference Classification
- **File:** `user_privacy_preference_classificaiton_final.ipynb`
- **Overview:** A predictive classification workflow designed to categorize and predict user privacy settings and preferences based on user behavior and interaction data.
